# OABP / AIGEN client SDKs

Multi-language client libraries for the OABP agent-bounty protocol (https://cryptogenesis.duckdns.org).

- `csharp` — Oabp.Client — .NET 8 SDK for the OABP / AIGEN protocol
- `dart` — OABP / AIGEN Dart SDK (`oabp`)
- `elixir` — OABP — Elixir SDK for the AIGEN Open Agent Bounty Protocol
- `go-mcp` — oabp-mcp-go
- `go` — oabp-go — Go SDK for the OABP / AIGEN protocol
- `java` — OABP Java SDK
- `kotlin` — OABP Kotlin SDK
- `php` — OABP PHP SDK
- `python-a2a` — oabp-a2a — OABP A2A JSON-RPC client (Python)
- `python-async` — OABP Async Python SDK
- `python-webhook-listener` — OABP feed listener (Python)
- `python` — OABP Python SDK
- `r` — oabp — OABP / AIGEN client for R
- `ruby` — OABP Ruby gem (`oabp`)
- `rust` — oabp-client
- `swift` — OABP Swift SDK
- `typescript-a2a` — @oabp/a2a-client
- `typescript` — @oabp/sdk
